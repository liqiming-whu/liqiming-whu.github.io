## 我是谁

生物信息学博士在读，快毕业了。

2021 年开这个博客的时候，我还是一位正在学生信的可怜研究生～

那时候的日常大概是这样的：写个脚本处理测序数据，脚本报错；查了一下午，发现是少了个 tab。修好之后顺手把终端和 vim 又配得顺手了一点，然后继续报错。

后来兴趣一路拐进了 AI Agent。现在大部分空闲时间都在给 [Operit](https://github.com/AAswordman/Operit)、SillyTavern、DeepSeek Harness 这些宿主写插件：让模型知道现在几点、天气如何，给角色加上长期记忆，或者把一套工作流整理成 Skill。生信的老本行也没丢，[pybiotk](https://github.com/liqiming-whu/pybiotk) 还在维护。做过的东西都列在[项目](/projects.html)页。

## 关于这个站

这个站最早是用旧手机一点点爬起来的 Hexo 小破站，后来重新整理成了现在的样子：文章写成 Markdown，由一个小小的 Python 脚本生成静态页面，推到 GitHub 就自动上线。

没有前端框架，没有第三方统计，也没有挡住文字的浮动挂件，只留下阅读本身。支持浅色和深色两种模式，深夜看也不刺眼。

## 写点什么

生信文件处理、Python 小工具、终端配置，以及给 AI Agent 写插件时踩过的坑，偶尔也有些没什么用的碎碎念。写下来一是怕自己忘，二是万一能帮到正卡在同一步的你。
