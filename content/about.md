## 关于这个站

这个站最早是用旧手机一点点爬起来的 Hexo 小破站，后来重新整理成了现在的样子：文章写成 Markdown，由一个小小的 Python 脚本生成静态页面，推到 GitHub 就自动上线。

没有前端框架，没有第三方统计，也没有挡住文字的浮动挂件，只留下阅读本身。支持浅色和深色两种模式，深夜看也不刺眼。

## 写点什么

这里大多是学习和折腾时的随手记录：Python 小工具、Linux 配置、生信文件处理，偶尔也有些没什么用的碎碎念。写下来一是怕自己忘，二是万一能帮到正卡在同一步的你。
